# 모두의 무전기

여러 사람이 브라우저로 함께 쓰는 무전기(PTT) 웹앱입니다. 앱 설치 없이 휴대폰·PC 브라우저에서 주소만 열면 됩니다.

## 기능
- **대기실**: 접속한 사람 전체 명단(대기실에 있는 사람 / 어느 방에 들어가 있는지)과 열린 방 목록
- **방**: 누구나 방을 만들 수 있고, 비밀번호를 걸 수 있음. 방장이 나가면 남은 사람에게 방장 위임, 모두 나가면 방 자동 삭제
- **채널**: 방 안에 들어온 사람만 보이고 쓸 수 있음
  - `방 인원 전체` 채널 또는 `선택한 인원만` 채널(체크한 사람만 듣고 말함)
  - 채널을 만든 사람·방장만 이름/권한 변경, 삭제 가능. 권한이 빠진 사람은 자동으로 공용 채널로 이동
- **자동 재연결**: 신호가 잠깐 끊겨도 원래 방·채널로 복귀
- **PTT 송신**: 버튼(또는 스페이스바)을 누르고 있는 동안 송신. 채널마다 한 번에 한 사람만 송신(서버가 송신권 관리), 한 번에 최대 60초
- 송신/수신 비프음, 수신 음량, 신호 레벨 표시, 화면 꺼짐 방지

## 바로 배포하기 (Render, 무료)
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/qmast1973/walkie-talkie)

1. 위 버튼을 누르고 GitHub 계정으로 Render에 로그인
2. 이 저장소 연결을 허용하고 **Apply** (설정은 `render.yaml`에 이미 들어 있음)
3. 몇 분 뒤 생기는 `https://walkie-talkie-xxxx.onrender.com` 주소를 동료들에게 공유
4. 휴대폰에서 그 주소를 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있음

## 현장에서 쓸 때
- 통신이 잠깐 끊겨도 45초 안에 돌아오면 원래 방·채널(선택 인원 채널 권한 포함)로 자동 복귀합니다.
- 브라우저 특성상 **화면이 켜져 있고 이 페이지가 앞에 떠 있어야** 수신됩니다. 앱이 화면 꺼짐을 막아 주지만, 다른 앱으로 전환하면 수신이 멈춥니다.
- Render 무료 요금제는 15분간 아무도 접속하지 않으면 잠들고, 다음 첫 접속 때 30~50초 걸립니다. 업무용으로 매일 쓰면 유료 요금제(월 7달러)로 바꾸면 항상 켜져 있습니다.

## 직접 실행
```bash
npm install
npm start          # http://localhost:3000
```
`PORT` 환경변수로 포트를 바꿀 수 있습니다.

## 배포할 때 꼭 알아둘 것
- 브라우저는 **https 주소에서만 마이크를 허용**합니다(localhost 제외). Render, Railway, Fly.io 같은 Node.js 호스팅에 올리면 https가 자동으로 붙습니다.
  - Render 예: New → Web Service → 이 저장소 선택 → Build `npm install`, Start `npm start`
- WebSocket을 쓰므로 GitHub Pages·Netlify 같은 정적 호스팅에서는 동작하지 않습니다.
- 접속 정보는 서버 메모리에만 있어서, 서버가 재시작되면 방과 채널이 초기화됩니다.

## 구조
- `server.js` — Express + Socket.IO. 사용자·방·채널·송신권 관리, 음성 프레임 중계
- `public/index.html` — 화면 전체(대기실, 방, 무전기)
- `public/capture-worklet.js` — 마이크 입력 캡처(AudioWorklet)

음성은 16kHz 모노 PCM(약 256kbps)으로 서버를 거쳐 같은 채널 사람에게만 전달됩니다.

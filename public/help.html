무전기 도움말

처음 설치설치·권한·배터리 무전하기송신 버튼·볼륨(-)·이어폰 방과 채널만들기·비밀 채널 방장 기능삭제·내보내기 인터넷 없이오프라인 무전 소리 크게시끄러운 현장 문제 해결안 들릴 때·끊길 때 데이터 사용량얼마나 쓰나요

처음 설치

  1. 휴대폰 인터넷 창에서 아래 주소를 열어 앱을 받고 설치해요.
    github.com/qmast1973/walkie-talkie/releases/latest/download/walkie-talkie.apk
  2. ‘출처를 알 수 없는 앱’ 경고가 나오면 설정 → 이 출처 허용을 켜고 설치해요.
  3. 앱을 처음 열면 마이크와 알림을 모두 허용해요.
  4. 닉네임을 정하고 대기실 입장을 눌러요. 같은 이름은 한 사람만 쓸 수 있어요.

화면이 꺼져도 들리게 (삼성 갤럭시)

  1. 앱 아이콘 길게 누르기 → ⓘ 애플리케이션 정보 → 배터리 → 제한 없음
  2. 설정 → 배터리 → 백그라운드 사용 한도 → 절전 예외 앱에 ‘모두의 무전기’ 추가
  3. 같은 화면의 사용하지 않는 앱을 절전 상태로 전환은 끄기
위쪽 알림창에 ‘무전기 대기 중’이 떠 있으면 화면이 꺼져도 무전이 들려요.

업데이트

대부분의 기능은 앱을 껐다 켜면 자동으로 바뀌어요. 새 앱을 받으라고 안내가 오면 위 주소로 다시 받아 그대로 설치(덮어쓰기)하면 돼요. 지울 필요 없어요.

무전하기

  • 화면 버튼: 아래 큰 PTT 버튼을 누르고 있는 동안 말해요. 손을 떼면 끝나요.
  • 볼륨(-) 버튼: 방 안에서 볼륨 아래 버튼을 누르고 있으면 송신돼요. 볼륨(+)은 원래대로 소리 크기 조절이에요.
  • 블루투스 이어폰: 재생 버튼을 한 번 누르면 송신 시작, 한 번 더 누르면 끝나요.
  • PC: 스페이스바를 누르고 있으면 송신돼요.

한 채널에서는 한 번에 한 사람만 말할 수 있어요. 누가 말하는 중이면 버튼이 잠기고 화면에 ◀ 이름이 보여요. 한 번에 최대 60초까지 송신돼요.

화면 표시: TX 내가 송신 중 · RX 수신 중 · STBY 대기

방과 채널

대기실

접속한 사람 명단과 열린 방 목록이 보여요. 방 이름을 쓰고 방 만들기를 누르면 내가 방장이 돼요. 비밀번호를 넣으면 아는 사람만 들어올 수 있어요.

채널

  • 방에 들어오면 01 공용 채널로 시작해요. 같은 채널에 있는 사람끼리 들려요.
  • 채널 버튼을 누르면 그 채널로 바뀌어요. 지금 쓰는 채널을 한 번 더 누르면 설정이 열려요.
  • + 채널로 새 채널을 만들어요. 선택한 인원만을 고르면 체크한 사람만 듣고 말할 수 있어요(🔒 표시).
  • 누가 말하고 있는 채널에는 빨간 점이 떠요.

잠깐 끊겨도 괜찮아요

신호가 끊기거나 앱을 다시 열어도, 원래 방과 채널로 자동으로 돌아가요.

방장 기능

  • 방 삭제: 방 화면 위쪽 또는 대기실 방 목록의 삭제를 두 번 눌러요. 안에 있던 사람은 대기실로 나가요.
  • 내보내기: 방 인원 목록에서 이름 옆 내보내기를 두 번 눌러요. 내보낸 사람은 자동으로 다시 들어오지 않아요.
  • 방장 이어받기: 방장이 1분 넘게 방에 없으면, 방에 있는 사람 중 먼저 들어온 사람이 방장이 돼요.
  • 아무도 없는 방은 24시간 뒤 자동으로 지워져요.

인터넷 없이 (오프라인 무전)

데이터나 와이파이가 없어도 근처 폰끼리 블루투스로 직접 무전해요.

  1. 폰의 블루투스와 위치를 켜요.
  2. 대기실의 오프라인 무전을 눌러요. 인터넷이 안 되면 앱이 자동으로 이 화면을 열어요.
  3. 처음 한 번 권한 허용을 누르고 모두 허용해요.
  4. 내 이름, 팀 이름, 채널(1~8)을 정하고 오프라인 무전 시작을 눌러요.
  5. 위쪽 연결 N대에 숫자가 올라가면 연결된 거예요. 처음엔 10~30초 걸릴 수 있어요.
같은 팀 이름과 같은 채널을 고른 사람끼리만 들려요. 팀 이름은 띄어쓰기까지 똑같이 맞춰 주세요.

폰끼리 직접 닿는 거리는 같은 층에서 수십 m 정도예요. 중간에 있는 폰이 소리를 이어서 전달해 주니, 동료들이 흩어져 있으면 더 멀리까지 들려요. 오프라인 무전과 인터넷 무전은 서로 따로예요.

소리 크게

  1. 폰의 미디어 볼륨을 최대로 올려요(앱 안에서 볼륨(+) 버튼).
  2. 갤럭시: 설정 → 소리 및 진동 → 음량 → ⋮ → 미디어 볼륨 제한이 켜져 있으면 꺼 주세요.
  3. 인터넷 무전: 송신 버튼 아래 음량을 최대 400%까지 올릴 수 있어요. 기본 200%가 유튜브와 비슷한 크기예요. 더 키우면 400%까지 돼요.
  4. 오프라인 무전: 아래 소리 키우기를 최대 +24dB까지 올릴 수 있어요. +6dB가 유튜브와 비슷한 크기, 기본 +12dB는 그보다 커요.
  5. 그래도 안 들리면 블루투스 이어폰·넥밴드를 써 보세요. 소음이 큰 곳에서는 훨씬 잘 들려요.
  6. 소리는 바깥 스피커로 나와요. 유선·블루투스 이어폰을 연결하면 자동으로 이어폰으로 나오고, 빼면 다시 스피커로 돌아와요.

문제 해결

소리가 안 들려요

  • 상대와 같은 방·같은 채널인지 확인해요(화면의 CH 번호).
  • 미디어 볼륨과 앱 음량이 0이 아닌지 확인해요.
  • 앱을 다시 열었다면 화면을 한 번 눌러 주세요(소리 켜기).

화면을 끄면 안 들려요

  • 위 처음 설치의 배터리 ‘제한 없음’과 절전 예외를 해 주세요. 대기실에 ‘대기 중 끊김 막기’ 안내가 뜨면 설정 열기를 누르세요.

송신 버튼이 안 눌려요

  • 다른 사람이 말하는 중이면 잠겨요. 끝나면 다시 눌러요.
  • 처음 한 번은 버튼을 누르면 마이크 켜기만 돼요. 한 번 더 누르고 말해요.

‘다른 사람이 쓰고 있어요’라며 이름이 안 돼요

  • 같은 이름이 이미 접속 중이에요. PC나 다른 폰에 같은 이름으로 열어 둔 화면이 있으면 닫거나, 다른 이름을 써요.

명단에 나간 사람이 남아 있어요

  • 잠깐 끊긴 사람은 45초 동안 ‘연결 끊김’으로 보였다가 사라져요. PC는 무전기 탭을 새로고침(F5)해 주세요.

오프라인에서 연결이 0대예요

  • 블루투스와 위치가 켜져 있는지, 권한을 모두 허용했는지 확인해요.
  • 상대도 오프라인 무전 시작을 눌렀는지 확인해요. 가까이(몇 m) 붙어서 먼저 연결해 보세요.

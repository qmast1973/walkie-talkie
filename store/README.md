## 스토어 등록정보 (기본 스토어 등록정보)
- **앱 이름**: 모두의 무전기
- **간단한 설명** (80자 이내):
  현장 동료끼리 쓰는 무전기. 방과 채널을 만들고 버튼을 누르고 말하세요.
- **자세한 설명**:
```
모두의 무전기는 같은 현장에서 일하는 동료끼리 쓰는 인터넷 무전기입니다.

■ 대기실과 방
- 대기실에서 접속한 사람과 열린 방을 한눈에 확인
- 방을 만들고 비밀번호를 걸 수 있어요
- 방장은 방 삭제와 인원 내보내기 가능

■ 방 안의 채널
- 방에 들어온 사람만 채널을 쓸 수 있어요
- '선택한 인원만' 채널로 특정 동료끼리만 무전

■ 무전기처럼
- 송신 버튼을 누르고 있는 동안 말하기(한 채널에 한 번에 한 사람)
- 볼륨(-) 버튼으로 송신, 블루투스 이어폰 버튼으로 송신 켜기/끄기
- 화면이 꺼져 있어도 '무전기 대기 중' 상태로 수신
- 통신이 잠깐 끊겨도 원래 방과 채널로 자동 복귀

■ 개인정보
- 회원가입 없이 닉네임만으로 사용
- 음성은 전달만 하고 저장하지 않습니다
```
- **앱 카테고리**: 커뮤니케이션
- **연락처 이메일**: (Play Console 계정 이메일 입력)

## 앱 콘텐츠 설문 답변
### 개인정보처리방침
`https://walkie-talkie-1zpg.onrender.com/privacy.html`

### 광고
광고 없음

### 앱 액세스 권한
"모든 기능을 특별한 액세스 권한 없이 사용할 수 있음" (닉네임만 입력하면 사용 가능)

### 콘텐츠 등급
- 카테고리: 커뮤니케이션(소셜·커뮤니케이션 앱)
- 사용자 간 소통(음성) 있음 → "예"
- 폭력·선정성·도박 등 → 모두 "아니요"

### 타겟층
만 18세 이상(또는 만 16세 이상). 아동 대상 아님.

### 데이터 보안
| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 예(수집), 공유 안 함 |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 방법 제공 | 예 (앱 삭제 시 24시간 내 자동 삭제, 문의로 즉시 삭제) |
| **오디오 › 음성 또는 소리 녹음** | 수집함 · 처리 후 저장 안 함(일시적 처리) · 목적: 앱 기능 · 필수 |
| **개인 정보 › 이름**(닉네임) | 수집함 · 목적: 앱 기능 · 필수 |
| **앱 정보 및 성능 / 기기 ID** | 기기 식별용 임의 키 → "기기 또는 기타 ID" 수집 · 목적: 앱 기능 |
| 위치·연락처·사진·금융 등 | 수집 안 함 |

### 포그라운드 서비스 권한 선언 (앱 콘텐츠 › 포그라운드 서비스)
- **유형**: 마이크(`FOREGROUND_SERVICE_MICROPHONE`), 미디어 재생(`FOREGROUND_SERVICE_MEDIA_PLAYBACK`)
- **사용 사례 설명**:
```
무전기(Push-to-talk) 앱입니다. 사용자가 방에 들어가 있으면 화면이 꺼지거나 다른 앱을 쓰는 중에도
동료의 무전(음성)을 실시간으로 받아 재생해야 하고(미디어 재생), 사용자가 볼륨(-) 버튼이나 블루투스 이어폰 버튼을
누르면 화면을 켜지 않고도 바로 말할 수 있어야 합니다(마이크). 서비스가 동작하는 동안 '무전기 대기 중' 알림이
항상 표시되며, 알림의 '종료'로 언제든 끌 수 있습니다. 마이크는 송신 버튼을 누르는 동안에만 소리를 보냅니다.
```
- **동영상 링크**: 화면을 끈 상태에서 다른 폰의 무전이 들리고, 볼륨(-) 버튼으로 답하는 장면을 30초 정도 찍어
  YouTube에 '일부 공개'로 올린 링크

## 테스트 트랙
- **내부 테스트**: 테스터 이메일(최대 100명)만 등록하면 바로 배포. 심사·12명 조건 없음.
  테스트 → 내부 테스트 → 새 버전 만들기 → `walkie-talkie.aab` 업로드 → 테스터 목록에 동료 구글 계정 추가 → 참여 링크 공유
- **프로덕션(일반 공개)**: 개인 계정은 비공개 테스트(12명 이상, 14일) 후 신청 가능

## 버전 올리기
GitHub Actions가 빌드할 때마다 버전 번호가 자동으로 올라갑니다. 새 `walkie-talkie.aab`를 받아 같은 트랙에 업로드하면 됩니다.
